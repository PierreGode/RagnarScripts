# Rubber Ducky payloads

`.ducky` / `.txt` USB HID keystroke-injection payloads. Install one from the
**Rubber Ducky** card in Ragnar (Pentest tab) → it is copied into
`files/rubber-ducky/` and selected. The demos here are deliberately harmless
(open an app, type a greeting, read-only recon). Authorized testing only.
